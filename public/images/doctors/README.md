# Hekim Fotoğrafları Klasörü

Hekim fotoğraflarını bu klasör içine, aşağıdaki isimlendirme standartlarına uygun olarak yükleyebilirsiniz:

- Hasan Sinankılı: `hasan-sinankili.jpg` (veya `.png`)
- Burak Şenol: `burak-senol.jpg` (veya `.png`)
- Seher Kocabaş: `seher-kocabas.jpg` (veya `.png`)
- Uğurcan Dağalp: `ugurcan-dagalp.jpg` (veya `.png`)
- Furkan Akyıldız: `furkan-akyildiz.jpg` (veya `.png`)
- Büşra Beyhan: `busra-beyhan.jpg` (veya `.png`)
- Emir Hacıoğlu: `emir-hacioglu.jpg` (veya `.png`)
- Senem Koç: `senem-koc.png` (veya `.jpg`)

Not: Eğer fotoğraflar harici bir URL (örn. Imgur vb.) yerine yerel klasörden okunacaksa, `/data/doctors.ts` içerisindeki `imageUrl` alanlarını `/images/doctors/hasan-sinankili.jpg` şeklinde güncelleyebilirsiniz.

# Klinik Ekibi Fotoğrafları

Bu klasöre klinik ekibimizin fotoğraflarını aşağıdaki dosya isimleriyle yükleyebilirsiniz:

- `ozkan-yasar.jpg` (Özkan Yaşar - Yönetici)
- `derya-sivri.jpg` (Derya Sivri - Asistan)
- `isil-isik.jpg` (Işıl Işık - Asistan)
- `samet-tabanli.jpg` (Samet Tabanlı - Danışma)
- `ecem-ecem.jpg` (Ecem Ecem - Danışma)

Önerilen format: `.jpg`, `.jpeg` veya `.png` (Önerilen boyut: 600x750px veya dikey portre oranı).
Fotoğraf yüklenmediğinde veya yüklenene kadar sistem otomatik olarak şık bir avatar kartı ve isim baş harflerini gösterir.
